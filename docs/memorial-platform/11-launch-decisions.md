# 11. 上线前决策

以下事项不阻塞里程碑 A，但必须在对应功能进入生产前形成书面政策。每项都明确决策责任和最晚时间。

## 1. 法律与运营主体

最晚时间：公开邀请非团队用户之前。

需要决定：

- 平台运营公司和注册司法辖区；
- 服务条款适用法律；
- GDPR、CCPA 及目标市场隐私义务；
- 数据保护联系人；
- 版权投诉渠道；
- 未成年人主页要求；
- 执法或法院请求流程。

责任：创始人、法律顾问、隐私负责人。

## 2. 数据保留

最晚时间：实现最终删除 Worker 之前。

需要决定：

- 主页删除恢复期；
- 导出文件有效期；
- 登录安全日志期限；
- 审计日志期限；
- 举报与申诉案件期限；
- 申诉证据期限；
- 备份保留和删除同步周期。

责任：隐私负责人、安全负责人、工程负责人。

## 3. 管理权优先级

最晚时间：管理权申诉上线前。

需要决定：

- 配偶、父母、子女、兄弟姐妹冲突时的处理原则；
- 多名同级亲属如何共同治理；
- 创建者失联或去世后的继承；
- 哪些争议需要证明；
- 临时冻结主页的门槛；
- 复核次数和最终裁决机制。

责任：产品负责人、法律顾问、治理负责人。

## 4. 宗教和文化审核

最晚时间：首个宗教仪式版本发布前。

需要决定：

- 顾问资格和利益冲突声明；
- 可接受资料来源；
- 审核人与发布人是否必须分离；
- 宗派争议的标注格式；
- 复审周期；
- 用户纠错响应时间；
- 紧急停用权限。

责任：宗教文化内容负责人、治理负责人。

## 5. 供应商

最晚时间：预发布环境搭建前。

需要选择：

- PostgreSQL；
- Redis；
- S3 兼容存储；
- 邮件；
- 短信；
- CDN/WAF；
- 日志、指标和错误监控；
- 恶意文件扫描；
- 翻译服务。

选择标准：

- 数据区域；
- 隐私协议；
- 可用性；
- 成本；
- 出口能力；
- 供应商锁定风险；
- 审计能力。

责任：工程负责人、财务负责人、隐私负责人。

## 6. 免费额度

最晚时间：里程碑 B 结束前。

需要决定：

- 每个账号可创建的主页数量；
- 照片、视频和音频容量；
- 单文件大小；
- 免费管理员人数；
- 导出频率；
- 纪念日通知是否属于免费权益。

默认产品方向保持：基础主页和基础祭奠永久免费。

责任：产品负责人、工程负责人、财务负责人。

## 7. 品牌和支持

最晚时间：公开测试前。

需要决定：

- 平台名称和域名；
- 宗教中立的品牌语言；
- 客服邮箱；
- 支持语言；
- 举报紧急联系方式；
- 状态页和安全联系地址。

责任：创始人、品牌负责人、治理负责人。

## 8. 上线批准

公开上线必须同时获得：

- 产品验收；
- 工程发布门槛通过；
- 隐私审查；
- 安全审查；
- 宗教文化内容审查；
- 备份恢复证据；
- 举报与紧急下架值班安排。
