# 08. 测试与质量

## 1. 测试分层

### 单元测试

覆盖纯业务逻辑：

- 权限矩阵；
- 宗教兼容规则；
- 历法适配器；
- locale 和 RTL；
- 文件类型策略；
- 限流键；
- 权益解析；
- Worker 重试。

### 集成测试

使用真实 PostgreSQL 和隔离 Redis：

- 登录挑战和会话；
- 主页创建事务；
- 隐私切换；
- 内容版本；
- 媒体状态；
- 宗教目录发布；
- 祭奠幂等；
- 搜索隐私；
- 举报和管理权申诉；
- 导出与删除。

### 端到端测试

使用 Playwright：

- 邮箱登录；
- 手机登录入口隐藏；
- 完整创建主页；
- 邀请家庭成员；
- 配置祭奠；
- 访客祭奠；
- 搜索公开主页；
- 转为仅受邀；
- 管理员权限；
- 多语言和 RTL；
- 无支付入口。

## 2. TDD 要求

每个业务任务按以下顺序执行：

1. 写一个明确失败的测试；
2. 运行并确认失败原因正确；
3. 编写最小实现；
4. 运行目标测试；
5. 运行相关回归测试；
6. 提交小而完整的变更。

测试不得只断言 HTTP 状态，还要验证数据库状态、审计事件、outbox 事件和不可见数据。

## 3. 权限矩阵

必须对以下角色逐项测试：

- 所有者；
- 管理员；
- 编辑者；
- 审核者；
- 受邀访客；
- 公开访客；
- 平台审核员；
- 超级管理员。

必须覆盖以下资源：

- 基本资料；
- 隐私；
- 成员；
- 内容；
- 媒体；
- 祭奠设置；
- 访客投稿；
- 导出；
- 删除；
- 申诉证据；
- 宗教目录发布。

## 4. 隐私测试

必测：

- 三种隐私模式；
- 未授权私密访问返回 404；
- 转私密后同步拒绝访问；
- 搜索索引延迟不导致泄露；
- sitemap 和结构化数据不包含私密主页；
- 私密媒体 URL 到期；
- 缓存失效；
- 删除恢复期和最终清理。

## 5. 宗教文化测试

- 无规则时不推荐；
- 推荐不会自动启用；
- 家属确认写入具体版本；
- 冲突采用最严格结果；
- 停用版本不能用于新主页；
- 已发布版本不可覆盖；
- 缺少来源不能发布；
- 只有机器翻译不能发布；
- 自定义动作默认只用于当前主页；
- 宗教历法不支持时明确失败，不猜测日期。

## 6. 非功能测试

- WCAG 2.2 AA 自动检查；
- 键盘和屏幕阅读器人工检查；
- 375px RTL 布局；
- 公开主页性能；
- 搜索限流；
- 大文件和恶意文件；
- 并发祭奠幂等；
- 数据库故障；
- Redis 故障；
- 通知供应商故障；
- 搜索任务积压；
- 备份恢复。

## 7. 发布门槛

每次候选发布必须通过：

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run db:migrate
npm run db:seed
npx tsx scripts/verify-backup-restore.ts
```

不得以“已知失败”跳过权限、隐私、宗教规则、删除或恢复测试。

## 8. 完成定义

一个功能只有满足以下条件才算完成：

- 验收条件明确；
- 测试先于或伴随实现；
- 服务端权限已实施；
- 输入有 Zod 校验；
- 错误码稳定；
- 审计和 outbox 按需存在；
- 英语、简体中文和西班牙语文案齐全；
- 阿拉伯语布局未被破坏；
- 相关文档更新；
- 迁移可在空数据库和上一版本数据库执行；
- 无新高危安全问题。
