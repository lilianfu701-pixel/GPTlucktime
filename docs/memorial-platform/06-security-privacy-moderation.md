# 06. 安全、隐私与内容治理

## 1. 信任边界

不可信输入包括：

- 浏览器提交的所有字段；
- 上传文件及其扩展名、MIME 和 EXIF；
- OAuth 回调；
- 邮件和短信供应商回调；
- 用户提供的宗教描述；
- 访客留言、媒体和举报；
- 搜索参数；
- 管理员自由文本。

所有权限在服务端执行。对象存储键、前端路由和不可预测 slug 都不能替代授权。

## 2. 登录安全

- 邮箱和短信验证码只保存哈希；
- 验证码十分钟过期；
- 六次错误后锁定挑战；
- 按账号、目标地址和 IP 限流；
- 会话令牌只保存哈希；
- Cookie 使用 `HttpOnly`、`Secure` 和适当 `SameSite`；
- 敏感变更要求近期登录或二次验证；
- Google/Apple 使用 state 和 nonce；
- OAuth 只按提供方 subject 绑定；
- 未验证的 OAuth 邮箱不能自动合并账号。

## 3. 权限原则

| 操作 | 所有者 | 管理员 | 编辑者 | 审核者 | 访客 |
|---|---:|---:|---:|---:|---:|
| 编辑基本资料 | 是 | 是 | 是 | 否 | 否 |
| 更改隐私 | 是 | 否 | 否 | 否 | 否 |
| 管理成员 | 是 | 是，不含所有权 | 否 | 否 | 否 |
| 发布家庭内容 | 是 | 是 | 是 | 否 | 否 |
| 审核访客投稿 | 是 | 是 | 否 | 是 | 否 |
| 配置祭奠 | 是 | 否 | 否 | 否 | 否 |
| 请求删除 | 是 | 否 | 否 | 否 | 否 |

平台审核员只能执行已定义治理动作，不能替家属改写生平。

## 4. 媒体安全

上传流程：

1. 授权并签发短期上传 URL；
2. 文件进入不可公开的隔离区；
3. 校验真实文件签名和大小；
4. 恶意文件扫描；
5. 图片移除 EXIF；
6. 生成安全衍生文件；
7. 状态变为 `ready`；
8. 按主页隐私签发读取 URL。

私密媒体不得拥有永久公共 URL。申诉证据使用不同存储前缀和访问角色。

## 5. 隐私要求

- 数据最小化；
- 性别为可选字段；
- 不强制精确生卒日期；
- 未成年人主页提示使用非公开模式；
- 私密主页不出现在搜索、站点地图或结构化数据；
- 转私密后同步撤销访问；
- 导出不包含其他用户私密安全数据；
- 删除包含恢复期和最终清理；
- 访问申诉证据本身写入审计。

## 6. 内容治理

举报类别：

- 身份冒用；
- 虚假死亡；
- 隐私侵害；
- 骚扰或仇恨；
- 暴力或露骨内容；
- 垃圾信息；
- 版权问题；
- 宗教或文化错误；
- 管理权争议；
- 其他安全问题。

案件状态：

```text
open → triaged → investigating → resolved/dismissed → appealed
```

平台动作：

- 限制编辑；
- 限制互动；
- 临时隐藏；
- 恢复；
- 屏蔽用户；
- 合并重复主页；
- 转移或恢复管理权；
- 停用有问题的仪式版本。

每次动作必须记录理由、操作者、资源、旧状态、新状态和关联 ID。

## 7. 管理权争议

- 系统不自动裁定亲属优先级；
- 争议期间可冻结所有权和隐私变更；
- 证据只对专门授权审核员可见；
- 双方收到处理结果；
- 允许一次复核；
- 合并主页保留作者身份和历史记录；
- 不将证明材料复制到普通内容或搜索索引。

具体亲属冲突优先级属于上线政策，记录在 `11-launch-decisions.md`。

## 8. 日志和敏感信息

禁止记录：

- 验证码；
- 会话令牌；
- OAuth code；
- 完整手机号和邮箱；
- 申诉证明正文；
- 私密留言正文；
- 对象存储签名 URL；
- 内部风险分数。

允许记录经过最小化和必要哈希处理的关联信息、稳定错误码、耗时和操作结果。

## 9. 威胁重点

上线前安全评审至少覆盖：

- 账号接管；
- SIM 换卡；
- OAuth 账号误合并；
- 私密主页枚举；
- IDOR 越权；
- 搜索批量抓取；
- 上传恶意文件；
- 存储签名 URL 泄漏；
- 管理员滥权；
- 祭奠刷量；
- 恶意重复主页；
- 申诉证据泄露；
- 缓存导致的隐私泄漏；
- 删除后数据残留。
