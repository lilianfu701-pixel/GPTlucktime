# 01. 产品需求

## 1. 产品愿景

为全球不同语言、宗教、文化和无宗教家庭提供可信、尊重隐私且可长期维护的线上追思空间。平台的核心价值是保存人生记录、连接亲友并支持适当的纪念方式，不制造祭奠竞争，也不替用户作宗教判断。

## 2. 目标用户

### 2.1 创建者

只有以下关系可以申请创建正式追思主页：

- 配偶；
- 父母；
- 子女；
- 兄弟姐妹。

创建者必须登录、验证身份渠道、声明关系并接受真实性及管理责任承诺。首版为轻审核，不默认上传死亡证明；出现重复、冒用或争议时可要求补充材料。

### 2.2 家庭协作者

所有者可以邀请：

- 管理员；
- 编辑者；
- 内容审核者；
- 受邀访客。

### 2.3 普通访客

访客可以根据主页权限：

- 搜索和访问公开主页；
- 通过链接访问非索引主页；
- 接受邀请访问私密主页；
- 执行家属允许的祭奠；
- 留言、分享回忆或投稿；
- 举报不实、侵权或有害内容。

## 3. 核心用户旅程

### 3.1 创建追思主页

1. 用户通过邮箱、Google 或 Apple 登录。
2. 选择与逝者的关系并作真实性声明。
3. 填写姓名、别名、生卒信息和地点。
4. 系统提示可能重复的主页。
5. 填写生平、时间线和媒体。
6. 选择宗教、宗派、文化或无宗教。
7. 家属逐项确认允许的祭奠方式。
8. 设置访问、搜索和互动权限。
9. 发布主页。
10. 系统异步建立搜索索引和媒体衍生文件。

### 3.2 访客祭奠

1. 系统验证主页访问权限。
2. 展示家属已经开启的祭奠方式。
3. 访客选择动作并可附短留言。
4. 系统执行限流和内容安全检查。
5. 按家属设置立即显示或等待审核。
6. 保存幂等记录并异步通知家属。

### 3.3 隐私切换

- 公开转仅链接：立即退出站内搜索并标记 `noindex`。
- 公开转仅受邀：立即拒绝未受邀访问。
- 私密转公开：所有者二次确认公开资料和搜索引擎收录。
- 删除：先进入恢复期，随后清理媒体、索引和派生数据。

## 4. 功能范围

### 4.1 身份

- 邮箱验证码登录；
- Google 和 Apple 登录；
- 会话、设备和异常登录记录；
- 手机验证码登录后端能力；
- 手机登录全球开关和地区开放名单；
- 手机绑定、解绑和安全账号合并。

手机号第一阶段不出现在前台，但必须通过自动化测试。

### 4.2 追思内容

- 头像和封面；
- 生平简介和完整传记；
- 人生时间线；
- 照片、视频和音频；
- 纪念文章、家书和公告；
- 葬礼、追思会和周年活动；
- 家庭关系展示；
- 访客故事和照片投稿；
- 分享链接、二维码和数据导出。

### 4.3 搜索

- 姓名、曾用名、原文姓名、音译和别名；
- 出生或逝世年份；
- 国家、地区和城市；
- 公开生平关键词；
- 模糊拼写；
- 重复主页候选。

仅公开主页进入搜索。系统不得提供热门逝者或祭奠排行榜。

### 4.4 隐私模式

| 模式 | 站内搜索 | 搜索引擎 | 访问要求 |
|---|---:|---:|---|
| 公开 | 是 | 家属可控制，默认是 | 任何人 |
| 仅链接 | 否 | 否 | 持链接者 |
| 仅受邀 | 否 | 否 | 登录且收到邀请 |

### 4.5 免费与高级权益

永久免费：

- 一个完整追思主页；
- 基础生平、时间线和媒体容量；
- 基础祭奠；
- 搜索、分享和隐私控制；
- 留言审核；
- 两名家庭管理员；
- 基础数据导出。

高级版预留：

- 更大媒体容量；
- 更多管理员和细分权限；
- 高级主题与自定义域名；
- 高清纪念册；
- 纪念日提醒；
- 私人线上活动；
- 访问分析；
- 批量上传；
- 长期数字保管。

第一阶段不显示购买入口，不创建真实支付交易。

## 5. 明确不做

- 原生移动应用；
- 自研直播；
- 政府死亡登记；
- 实体遗体、骨灰或墓地管理；
- 强制死亡证明；
- 公开祭奠排名；
- 付费虚拟祭品竞争；
- NFT、加密货币或数字遗产交易；
- 自动生成宗教教义结论；
- 未经人工审核发布宗教规则。

## 6. 成功标准

- 合格家属可完整创建和管理主页；
- 默认公开主页可以搜索；
- 转为私密后同步阻止未授权访问；
- 家属完全控制祭奠方式；
- 宗教规则具有来源、范围、翻译和审核记录；
- 举报和管理权申诉可以闭环处理；
- 英语、简体中文和西班牙语达到发布质量；
- 阿拉伯语 RTL 技术验证通过；
- 手机登录功能测试通过但入口隐藏；
- 数据备份能够恢复。
