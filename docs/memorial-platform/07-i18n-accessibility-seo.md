# 07. 多语言、无障碍与 SEO

## 1. 语言策略

界面语言和用户内容语言分开保存。用户切换界面语言不会自动改变逝者姓名或原文内容。

发布批次：

1. 英语 `en`、简体中文 `zh-CN`、西班牙语 `es`
2. 巴西葡萄牙语 `pt-BR`、法国法语 `fr`、德语 `de`
3. 阿拉伯语 `ar`、繁体中文 `zh-TW`/`zh-HK`、日语 `ja`
4. 俄语 `ru`、印尼语 `id`、越南语 `vi`、韩语 `ko`

系统同时识别 `pt-PT`，但不把巴西葡萄牙语文案直接标记为葡萄牙版本。

## 2. Locale 路由

- 页面路径以 locale 开头，例如 `/en/memorials/...`；
- `/api` 不做 locale 路由重写；
- `/` 根据用户选择、Cookie、浏览器语言和默认英语重定向；
- 每个请求显式设置 `lang`；
- 阿拉伯语设置 `dir="rtl"`；
- 用户选择的语言优先于自动识别。

## 3. 文案管理

- 所有界面文案使用稳定键；
- 首发三个语言包必须具有相同键集合；
- 禁止在组件中拼接不可翻译的句子；
- 数量、性别和复数使用 ICU 格式；
- 日期、数字和时区使用 `Intl`；
- 错误码和展示文案分离；
- 宗教术语使用单独术语表；
- 机器翻译不得直接成为已发布宗教文案。

## 4. 姓名和搜索

- 姓名不强制翻译；
- 保存原文、音译、曾用名和别名；
- 显示顺序按 locale；
- 不假设所有姓名都有姓和名两个字段；
- 搜索索引包含被允许搜索的别名和音译；
- 用户可标记某个别名不可公开搜索；
- Unicode 规范化不能丢失原始输入。

## 5. RTL

RTL 验收包含：

- 整页方向；
- 导航和面包屑；
- 表单标签和输入；
- 图标方向；
- 时间线；
- 媒体画廊；
- 模态框；
- 祭奠动作列表；
- 错误提示；
- 375px 宽度无横向溢出。

方向性图标使用逻辑方向；不应镜像播放、下载、宗教符号等具有固定含义的图标。

## 6. 无障碍

目标：WCAG 2.2 AA。

关键要求：

- 全流程键盘可操作；
- 焦点可见；
- 页面标题和区域层级正确；
- 表单具有可访问名称和错误关联；
- 上传进度对辅助技术可读；
- 图片要求替代文本或明确标记为装饰；
- 视频支持字幕字段；
- 音频支持文字说明字段；
- 不只用颜色表达审核状态；
- 动画遵守 `prefers-reduced-motion`；
- 祭奠动作不使用只有图标的无标签按钮；
- 隐私和公开确认使用清楚的风险文案。

## 7. SEO

仅公开且允许索引的主页：

- 进入 sitemap；
- 输出 canonical；
- 输出可用翻译的 hreflang；
- 输出安全的结构化数据；
- 允许公开媒体缩略图；
- 使用稳定 slug。

仅链接和仅受邀主页：

- `noindex, nofollow`；
- 不进入 sitemap；
- 不输出公开结构化数据；
- 不允许公共 CDN 缓存；
- 不因 Open Graph 预览泄露内容。

## 8. 隐私变化

主页转为非公开后：

1. 服务端访问策略立即生效；
2. 搜索查询立即排除；
3. 页面缓存失效；
4. sitemap 排除；
5. 页面输出 `noindex` 或 404；
6. 异步删除搜索文档；
7. 必要时向搜索引擎提交移除请求。

搜索引擎旧缓存无法保证立即消失，产品文案应明确说明。
