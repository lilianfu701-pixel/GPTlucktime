# DateCN 可见版界面设计

## 1. 目标

在不扩展后台功能范围的前提下，把现有能力组织成一套可以直接查看、点击和演示的完整交友网站。用户即使没有注册，也能通过演示模式体验主要页面；登录后仍可继续接入现有真实 API。

本阶段以“看得见、用得懂、移动端顺手”为成功标准。

## 2. 已确认选择

- 品牌：**DateCN**
- 域名：`datecn.org`
- 视觉：**A · 暖金可信**
- 数据：**演示模式**，与真实账户和生产数据隔离
- 受众：全球用户，不限定性别、性取向或地区
- 语言：英文与简体中文

## 3. 视觉系统

### 色彩

- 主色：酒红 `#8F2638`
- 深主色：`#6F1D2D`
- 背景：暖奶油 `#FFF9F3`
- 强调：柔金 `#D4A95D`
- 正文：深棕黑 `#2D2023`
- 次级文字：灰玫瑰 `#806B70`

### 气质

成熟、可信、温暖、国际化。保留参考网站“快速注册、浏览会员、开始交流”的高转化结构，但减少旧式门户感，使用更大的图片、留白、圆角卡片和清晰的安全提示。

### 字体与图形

- 标题使用有轻微杂志感的衬线字体回退组合。
- 正文使用清晰的无衬线字体。
- 图标采用轻量线性风格；不用 emoji 充当正式导航图标。
- 动效控制在淡入、卡片位移和按钮反馈，尊重 `prefers-reduced-motion`。

## 4. 页面结构

### 4.1 品牌首页

- 顶部：DateCN 品牌、语言切换、登录入口。
- 首屏：全球包容型主标题、免费开始按钮、三张真实感会员卡。
- 信任条：资料认证、全球会员、安全聊天。
- 会员预览：可横向浏览的演示会员。
- 三步流程：建立资料、浏览匹配、开始交流。
- 会员权益、成功故事、安全说明和页脚。

### 4.2 注册与登录

- 桌面端使用左右分栏：品牌故事/信任信息 + 表单。
- 移动端只保留表单和必要说明。
- 支持登录、创建账户、忘记密码入口和语言切换。
- 表单有清晰标签、错误、密码显示和键盘焦点状态。

### 4.3 搜索发现与匹配

- 桌面端：左侧筛选，右侧会员卡片网格。
- 移动端：单张沉浸卡片与可展开筛选抽屉。
- 支持推荐、在线、最新加入、已认证和高级筛选视觉状态。
- 演示模式提供多地区、多性别的示例资料。

### 4.4 个人资料

- 大图相册、认证标记、基本资料、关系目标、兴趣和自我介绍。
- 喜欢、收藏、发消息为固定主操作。
- 自己的资料页包含完成度和编辑入口。

### 4.5 消息

- 桌面端：会话列表、聊天内容、资料摘要三栏布局。
- 移动端：会话列表和单个聊天页面分层导航。
- 显示未读、在线、发送状态、图片占位和安全提示。

### 4.6 会员中心

- 免费、Plus、Premium 三档对比。
- 当前套餐、可用权益、用量和升级按钮。
- 使用清晰的月付展示；演示模式不调用真实 Stripe。

### 4.7 移动端导航

- 底部固定四项：发现、匹配、消息、我的。
- 会员中心从“我的”和页面升级入口进入。
- 最小触控目标 44px，支持安全区和单手操作。

## 5. 演示数据

- 演示数据放在独立模块中，使用固定 ID 和稳定内容。
- 不写入数据库，不与真实登录用户合并，不触发真实消息、支付、举报或通知。
- 页面明显显示“演示模式”标记。
- 示例资料覆盖不同地区、性别、年龄和关系目标。
- 所有头像使用项目内许可明确的占位资源或生成资源，不直接盗用参考网站图片。

## 6. 技术结构

- 继续使用 Next.js App Router、React Server Components、Tailwind CSS 和 `next-intl`。
- 建立共享的 `SiteHeader`、`MemberShell`、`MobileNav`、`ProfileCard`、`DemoBanner`、`PlanCard` 和 `EmptyState`。
- 演示模式通过只读数据服务注入，不在每个页面重复硬编码。
- 真实页面保留现有服务端鉴权和 API 接口；演示入口使用明确的 demo 路由/状态，不降低生产鉴权。
- 图片使用 `next/image`，关键首屏图片预加载，其余延迟加载。

## 7. 响应式规则

- 手机：`< 768px`，底部导航、单列卡片、抽屉筛选。
- 平板：`768–1023px`，双列卡片和紧凑导航。
- 桌面：`>= 1024px`，侧栏、三列资料卡和多栏消息布局。
- 页面不得产生横向滚动；360px 宽度仍可完成主要操作。

## 8. 可访问性与质量

- 颜色对比达到 WCAG AA。
- 所有表单、弹窗、抽屉和导航支持键盘操作。
- 图片有语义化替代文本，图标按钮有可见或屏幕阅读器标签。
- 中文和英文不截断；长姓名、长地区和长消息有安全布局。
- 组件测试覆盖桌面/移动关键状态；使用浏览器进行 360px、768px、1440px 视觉检查。

## 9. 本阶段不做

- 不增加新的后台审批、风控或计费规则。
- 不接入真实支付扣款。
- 不部署到生产域名。
- 不追求与 ChinaLoveCupid 像素级复制，也不复制其商标、图片或受版权保护文案。

## 10. 验收标准

1. 七个核心页面都能从首页或导航到达。
2. 未登录用户可进入演示模式并查看完整内容。
3. 中文、英文和移动端均无明显布局问题。
4. 视觉统一使用 DateCN 暖金系统。
5. 演示操作不会写真实数据库或调用真实支付/消息。
6. TypeScript、ESLint、组件测试、生产构建通过。
7. 提供本地预览地址和关键页面截图，供用户决定下一步。
